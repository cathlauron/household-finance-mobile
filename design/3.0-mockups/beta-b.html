Finance Flow Beta: what changes

Each phone plays the real taps by itself, then starts again. Nothing is built yet. Tell me what to change, or say approved.

1. Adding a trip

Only the name, the dates and the Savings switch. The budget and to-do are gone from this form. After Add, the new trip opens by itself, ready for its lists.

2. No Edit button

The top right of a trip is now empty. Tap the trip name to change it, the same way the calendar icon changes the dates.

3. Budget list

Tap an item and it opens right there in the list. + Add an item opens the same drop-down: item, cost, note and date. The circle on the left still ticks it as paid.

4. To-do list

Works the same as the Budget list, with the same four boxes. Remove now sits inside the drop-down, so the list stays clean.

5. Calendar

November ends on a Monday, so December 1 to 5 fill the last row, greyed out. Tapping one moves to December. Tapping a greyed November day moves back.

My suggestions (say no to any)

  • The new trip opens after Add, so you land on its Budget instead of the list.
  • A small pencil beside the trip name, so people can tell it can be tapped.
  • Remove inside the drop-down on both lists. It still asks before removing.
  • One drop-down open at a time. Opening another closes the first without saving it.

What stays the same

  • Delete trip stays at the bottom of the trip, and swiping still deletes from the list.
  • Editing a paid item's cost still updates its payment and your balance.
  • Greyed days show in Compact, Details and List views, with no dots. The small months in the year view don't change.

Two questions for you

  1. A cost on a to-do: should it add to the trip's Budget? I suggest no. It stays a reminder, so the Budget list is the only place that counts money.
  2. Where should Beta show? I suggest both places below.
